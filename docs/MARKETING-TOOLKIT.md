# Free author marketing toolkit

Marketplace should keep helping after a title becomes sellable.

Each live book can generate:

- canonical Marketplace URL
- campaign-specific tracking URL
- QR code
- HTML book card / buy button
- social launch copy
- short social copy
- event copy
- email/newsletter copy
- author website link
- source / medium / campaign attribution

## Attribution rule

Generated assets point to the Marketplace book listing, not directly to a fulfillment provider. That keeps campaign attribution in YasReady and lets one URL represent all available formats.

A campaign can preserve:

- `utm_source`
- `utm_medium`
- `utm_campaign`
- `yr_campaign` (Marketplace campaign ID)

When checkout is enabled, the order stores `campaign_id` so visits, orders and revenue can later be analyzed together.

## Ingram-inspired, YasReady-owned

IngramSpark publicly supports sharing Share & Sell links as URLs, QR codes and HTML embeds. YasReady uses the same low-friction promotional concepts while keeping the canonical destination on the YasReady listing so the author gets cross-format attribution.
