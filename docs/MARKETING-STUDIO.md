# Marketplace | YasReady v0.9 — Marketing Studio

Marketing Studio turns Marketplace attribution into an author growth workspace. Every generated asset points to the canonical YasReady listing and preserves campaign attribution.

## Core capabilities

- Trackable campaign links by book, channel and objective.
- Optional short-link records owned by Marketplace.
- QR, website button/embed, social, email and event copy from one campaign.
- Launch kits with reusable checklists.
- Campaign cost records so Marketplace can calculate ROAS when the author supplies spend.
- Channel comparison using visits, orders, revenue, refunds, conversion and revenue per visit.
- Rule-based recommendations that explain the evidence used.

## Data ownership

Publishing still owns production truth. Marketplace owns listings, promotion, attribution and commercial analytics. Marketing Studio never edits ISBNs, production files or Publishing artifacts.

## Safety

Recommendations are descriptive and evidence-based. No ad platform posting or paid media spend is performed in v0.9. Short links are server redirects and remain disable-able.
